## #

- **# memory shortcut** — A reported non-slash input where starting a message with # adds a memory line. NOT documented in current Claude Code memory docs; the supported quick paths are /memory and natural-language requests ('remember…', 'add this to CLAUDE.md'). Should not be relied on. _([Claude Code — Slash Commands](./claude-code/slash-commands.md))_
- **$ARGUMENTS** — Placeholder expanding to the full argument string typed after the command; if absent, args are appended as 'ARGUMENTS: <value>'. Indexed forms $ARGUMENTS[N] and shorthand $N access positional args (0-based, shell-style quoting). _([Claude Code — Slash Commands](./claude-code/slash-commands.md))_
- **${CLAUDE_PLUGIN_DATA}** — Persistent per-plugin directory at ~/.claude/plugins/data/{id}/ (id = plugin identifier with non-[A-Za-z0-9_-] replaced by -) that survives plugin updates; used for node_modules, virtualenvs, caches, generated state. Deleted on final-scope uninstall unless --keep-data is passed. _([Claude Code Plugins](./capabilities/plugins.md))_
- **--agent flag** — A CLI flag (or the 'agent' setting) that runs the whole session as a given subagent: its system prompt replaces the default Claude Code system prompt, and its tool restrictions and model apply session-wide; the choice persists on resume and the CLI flag overrides the setting. _([Claude Code — Subagents](./claude-code/subagents.md))_
- **--allowedTools / --disallowedTools** — Pre-approve tools to run without prompting, or deny/remove tools using permission-rule syntax. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--append-system-prompt** — Append custom text to the default system prompt (preserving tool guidance and safety instructions). _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--bare** — Minimal mode that skips discovery of hooks/skills/plugins/MCP/auto-memory/CLAUDE.md for faster scripted calls. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--continue / -c** — Load the most recent conversation in the current directory. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--dangerously-skip-permissions** — Skip all permission prompts; equivalent to --permission-mode bypassPermissions. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--fork-session** — When resuming, create a new session ID instead of reusing the original. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--output-format** — Print-mode output shape: text (default), json (single object with result + metadata), or stream-json (newline-delimited events). _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--permission-mode** — Start in a permission mode: default, acceptEdits, plan, auto, dontAsk, or bypassPermissions. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--print / -p** — Run a query headless (non-interactive), print the result to stdout, and exit — the basis of all scripting and piping. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **--resume / -r** — Resume a prior session by ID or name, or open the session picker. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **.claude/agents** — Project-scoped directory (priority 3) holding Markdown-with-frontmatter subagent definitions, discovered by walking up to the repo root and scanned recursively; check into VCS to share with a team. As of v2.1.178 the definition closest to the working directory wins among nested dirs. _([Claude Code — Subagents](./claude-code/subagents.md))_
- **.mcp.json** — Project-scoped MCP configuration at a repository root listing servers under mcpServers; checked into version control to share servers with a team, supports ${VAR} and ${VAR:-default} expansion in command/args/env/url/headers, and requires per-user approval before first use. _([Model Context Protocol (MCP)](./capabilities/mcp.md))_
- **/agents** — Interactive command opening a tabbed manager with a Running tab (live/finished subagents) and a Library tab (view, create via guided setup or Generate with Claude, edit, delete). Changes here take effect immediately without a session restart. _([Claude Code — Subagents](./claude-code/subagents.md))_
- **/design** — Companion Claude Code integration command to create, edit, and sync Claude Design projects without leaving the terminal. Not in the core Claude Code commands reference; arguments/version unconfirmed. _([Claude Design](./platform/claude-design.md))_
- **/design-sync** — Claude Code integration command (reported v2.1.181+) that two-way syncs a design system between repo and Claude Design: pull imports tokens/components into Claude Design; push sends the implemented state back. Builds a plan and returns a planId you must approve. Not in the core Claude Code commands reference. _([Claude Design](./platform/claude-design.md))_
- **/fire endpoint** — A per-routine HTTPS POST endpoint (api.anthropic.com/v1/claude_code/routines/{trig_...}/fire) that, called with the routine's 'sk-ant-oat01-' bearer token and the 'experimental-cc-routine-2026-04-01' beta header, starts a new cloud session and returns its session ID/URL. Optional freeform 'text' field (max 65,536 chars) passes run context; no idempotency key (retries create duplicate sessions); returns 503 (not 529) when overloaded; claude.ai-only with no SDK support. _([Claude Code — Dispatch, Remote Control & Routines](./claude-code/dispatch-remote-routines.md))_
- **/mcp command** — Claude Code interactive command opening the MCP panel: per-server connection status, tool count, source (plugin/claude.ai connector), pending/rejected project-server state, and OAuth Authenticate/Clear-authentication controls. _([Model Context Protocol (MCP)](./capabilities/mcp.md))_
- **/schedule** — Cowork command (also reachable via the Scheduled sidebar item; shipped Feb 25 2026) that sets a task to run on-demand or on a recurring cadence; scheduled runs only fire while the computer is awake and Claude Desktop is open. _([Claude Cowork](./platform/cowork.md))_
- **/terminal-setup** — Installs Shift+Enter and related multiline keybindings for terminals that need them (VS Code, Cursor, Devin Desktop, Alacritty, Zed). _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **1M context window** — 1,000,000-token working memory on Fable 5/Mythos 5/Opus 4.8/4.7/4.6/Sonnet 4.6 via the Claude API, Bedrock, and Google Cloud with NO beta header (verified); 200K on Foundry Opus 4.8 and Sonnet 4.5/Haiku 4.5/older. Default maximum on Fable 5/Mythos 5. No long-context price premium on Opus 4.8/4.7. _([Model Capabilities & Modes](./models/capabilities-and-modes.md))_
- **5-hour window** — The rolling usage window governing most Claude app message limits; its caps were doubled on May 6, 2026 for Pro, Max, Team, and seat-based Enterprise plans (with peak-hour reductions removed), tied to Anthropic's compute expansion. Weekly caps were not changed. _([Claude.ai & the Claude Apps](./platform/claude-ai.md))_

## A

- **acceptEdits mode** — Permission mode that auto-approves file edits and common in-scope filesystem commands (mkdir, touch, rm, rmdir, mv, cp, sed), plus PowerShell equivalents when the PowerShell tool is enabled, so you review changes after the fact. _([Claude Code — Overview](./platform/claude-code.md))_ · also: [Claude Code — Settings](./claude-code/settings.md)
- **Act without asking** — Cowork permission mode in which Claude proceeds through steps without pausing for approval; permanently deleting files still triggers a permission prompt. _([Claude Cowork](./platform/cowork.md))_
- **Adaptive thinking** — Reasoning mode (Fable 5 / Opus 4.6+ / Sonnet 4.6) where Claude decides whether and how much to think per request and interleaves thinking between tool calls. Enabled with thinking:{type:"adaptive"}; replaces deprecated fixed budget_tokens (which 400s on Fable 5/Opus 4.8/4.7). _([Model Capabilities & Modes](./models/capabilities-and-modes.md))_
- **Adjustment sliders (knobs)** — Custom sliders Claude generates per design to tune spacing, color, and layout live on the canvas, applied across the full design. _([Claude Design](./platform/claude-design.md))_
- **Agent loop** — Claude Code's iterative cycle of read context, reason/plan, call a tool, observe the result, and repeat, pausing only for permission gates or explicit questions. _([Claude Code — Overview](./platform/claude-code.md))_
- **Agent Mode / Cowork** — A more autonomous operating mode in which Claude performs multi-step work; on desktop it manifests most fully as Cowork (an agent in a local VM, GA April 9 2026) plus persistent agent threads monitorable from desktop/mobile. _([Claude.ai & the Claude Apps](./platform/claude-ai.md))_
- **Agent Skill** — A reusable, filesystem-based package that gives Claude domain-specific expertise: a folder containing a SKILL.md (instructions + YAML metadata) plus optional scripts, reference docs, and assets, loaded on demand when relevant to a request. _([Agent Skills](./capabilities/skills.md))_
- **Agent tool** — The built-in tool the parent uses to spawn subagents. Renamed from Task in v2.1.63; Task(...) still aliases. Spawns show as tool_use name 'Agent' (or 'Task' in older SDK system:init lists) with the type in input.subagent_type; deny 'Agent' in permissions.deny to block all delegation. _([Claude Code — Subagents](./claude-code/subagents.md))_
- **Agent View** — The unified session list/sidebar at claude.ai/code (and under Code in the mobile app) where all coding sessions—local Remote Control, cloud web tasks, Routine runs, Slack/Dispatch-spawned sessions—are managed: review diffs, share, archive, delete. 'Agent View' is an informal name; official docs only call it the session list/sidebar (in-product label unverified). _([Claude Code — Dispatch, Remote Control & Routines](./claude-code/dispatch-remote-routines.md))_
- **AgentDefinition** — The Claude Agent SDK object defining a subagent via the agents option: required description and prompt, plus tools, disallowedTools, model, skills, memory, mcpServers, initialPrompt, maxTurns, background, effort (low|medium|high|xhigh|max|number), and permissionMode. Python SDK uses camelCase field names; programmatic definitions override filesystem agents of the same name. _([Claude Code — Subagents](./claude-code/subagents.md))_
- **allowed-tools** — Lists tools Claude may use without per-use permission prompts while the skill is active; it pre-approves rather than restricts the tool pool. Experimental in the agentskills.io open standard (support varies across agents); fully supported in Claude Code, where it takes effect after accepting workspace trust for project skills. _([Agent Skills](./capabilities/skills.md))_
- **ANTHROPIC_SMALL_FAST_MODEL** — Environment variable overriding the small/fast model used for background pilot actions (e.g. claude-haiku-4-5). _([Claude Code — Settings](./claude-code/settings.md))_
- **Approval mode** — Enterprise per-connector role control with values Always allow, Needs approval, Blocked, or Custom; Custom expands the connector into per-tool rows each set independently. Blocked hides the connector/tool from members with that role. _([Connectors](./capabilities/connectors.md))_
- **Artifact** — A standalone, self-contained piece of content (significant/reusable, typically over 15 lines) that Claude renders in a dedicated side panel separate from chat, with its own version history and lifecycle; can be copied, downloaded, published, embedded, shared, or remixed. _([Artifacts](./capabilities/artifacts.md))_
- **Artifacts panel** — The dedicated right-side window in claude.ai where an artifact is rendered, with lower-right controls for viewing code, copying, downloading, fixing errors, and selecting versions. _([Artifacts](./capabilities/artifacts.md))_
- **Ask before acting** — Recommended Cowork permission mode (Settings > Cowork) in which Claude pauses for user approval on each action (edit, create, move, tool call) before proceeding. _([Claude Cowork](./platform/cowork.md))_
- **Auto memory** — Notes Claude writes for itself across sessions (build commands, debugging insights, preferences), on by default since v2.1.59, stored per repository at ~/.claude/projects/<project>/memory/ with a MEMORY.md index (first 200 lines / 25 KB loaded each session). _([Claude Code — Overview](./platform/claude-code.md))_
- **auto mode** — Research-preview permission mode (v2.1.83+, all plans) that runs actions without routine prompts while a separate classifier model blocks escalations such as curl|bash, prod deploys, or force-push to main; drops blanket code-exec allow rules while active. Opus 4.6+/Sonnet 4.6 on the Anthropic API; only Opus 4.7/4.8 on Bedrock/Vertex/Foundry (needs CLAUDE_CODE_ENABLE_AUTO_MODE=1). _([Claude Code — Overview](./platform/claude-code.md))_ · also: [Claude Code — Settings](./claude-code/settings.md)

## B

- **BASH_MAX_TIMEOUT_MS** — Maximum allowed Bash timeout in milliseconds; default 600000 (10 minutes), not 5 minutes. _([Claude Code — Settings](./claude-code/settings.md))_
- **Batch API** — POST /v1/messages/batches — async bulk processing at 50% of token prices, up to 100,000 requests/256MB per batch, results retained 29 days and returned out of order (key by custom_id). First-party + Claude Platform on AWS only; Fast mode not supported. _([Model Capabilities & Modes](./models/capabilities-and-modes.md))_
- **Bundled skill** — A prompt-based command shipped with Claude Code (e.g. /code-review, /batch, /debug, /loop, /claude-api) that Claude can also auto-invoke; appears in /skills, marked 'Skill' in the commands reference. Removable via disableBundledSkills. _([Claude Code — Slash Commands](./claude-code/slash-commands.md))_
- **Bundled skills** — Prompt-based Skills shipped with Claude Code (/code-review, /batch, /debug, /loop, /claude-api, plus /run, /verify, /run-skill-generator which need v2.1.145+) available every session unless disabled via disableBundledSkills. _([Agent Skills](./capabilities/skills.md))_
- **Bundled workflow** — A built-in dynamic workflow command (e.g. /deep-research) that fans work out across many subagents and runs in the background. _([Claude Code — Slash Commands](./claude-code/slash-commands.md))_
- **bypassPermissions mode** — Permission mode that skips all permission prompts and safety checks (the 'yolo' mode); intended only for isolated containers/VMs and refuses to start as root. As of v2.1.126 it also auto-approves protected-path writes, though rm -rf / and rm -rf ~ still prompt. _([Claude Code — Overview](./platform/claude-code.md))_

- **Routine** — A saved Claude Code configuration (prompt + GitHub repos + cloud environment + connectors) that runs autonomously on Anthropic-managed cloud infrastructure on a trigger: scheduled/cron (min 1-hour interval), an authenticated POST to a per-routine /fire endpoint, or GitHub PR/Release events. Created at claude.ai/code/routines or via '/schedule'; belongs to your individual account and counts against a per-account daily run cap. _([Claude Code — Dispatch, Remote Control & Routines](./claude-code/dispatch-remote-routines.md))_

## S

- **Sampling** — An MCP client feature letting a server request an LLM completion from the host via sampling/createMessage, so the server stays model-independent without bundling its own LLM SDK. _([Model Context Protocol (MCP)](./capabilities/mcp.md))_
- **sandbox** — Settings object configuring OS-level Bash isolation: enabled, failIfUnavailable, allowUnsandboxedCommands, excludedCommands, filesystem.{allowWrite,denyWrite,denyRead,allowRead}, network.{allowedDomains,deniedDomains,httpProxyPort,socksProxyPort}, credentials, plus autoAllowBashIfSandboxed and allowAppleEvents. _([Claude Code — Settings](./claude-code/settings.md))_
- **settings precedence** — The order managed settings > command-line flags > .claude/settings.local.json > .claude/settings.json > ~/.claude/settings.json; for permission rules and array sandbox keys all scopes merge and a deny at any layer is final. _([Claude Code — Settings](./claude-code/settings.md))_
- **settings.json** — Claude Code's JSON configuration file, present at user (~/.claude/), shared-project (.claude/settings.json), local-project (.claude/settings.local.json), and managed (system policy) scopes, merged by precedence. _([Claude Code — Settings](./claude-code/settings.md))_
- **Shared project** — A Team/Enterprise-only project shared by name/email/bulk/org-wide with 'Can use' (view+chat) or 'Can edit' (modify knowledge, instructions, and member settings); only the creator can remove access; recipients get email notifications and find it under 'Shared with me'. _([Projects](./capabilities/projects.md))_
- **Shell mode (! prefix)** — A leading ! runs a shell command directly, adds its output to context, and (v2.1.186+) has Claude respond automatically. _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **Shift+Tab** — Cycle permission modes: default → acceptEdits → plan → any enabled modes (auto, bypassPermissions). _([Claude Code — CLI Flags & Keyboard Shortcuts](./claude-code/cli-and-shortcuts.md))_
- **Skill content lifecycle** — In Claude Code an invoked SKILL.md enters the conversation as one message and stays for the session (not re-read); on auto-compaction it is re-attached keeping the first 5,000 tokens per skill within a combined 25,000-token budget filled from most recently invoked. _([Agent Skills](./capabilities/skills.md))_
- **Skill tool** — The model-invocation mechanism exposing user-invocable skills to Claude. Governed by Skill(name) (exact) / Skill(name *) (prefix) permission rules and the 1%-of-context listing budget (skillListingBudgetFraction / SLASH_COMMAND_TOOL_CHAR_BUDGET). 'SlashCommand' is the legacy/SDK name for the same idea. _([Claude Code — Slash Commands](./claude-code/slash-commands.md))_
- **SKILL.md** — The required entry-point file of a Skill: YAML frontmatter (at minimum name and description) between --- markers, followed by a Markdown body of instructions. The directory name typically becomes the invocation name. _([Agent Skills](./capabilities/skills.md))_
- **skillOverrides** — Settings key controlling per-skill visibility without editing SKILL.md: values on / name-only / user-invocable-only / off; written by the /skills menu to .claude/settings.local.json; does not affect plugin skills. _([Claude Code — Slash Commands](./claude-code/slash-commands.md))_ · also: [Agent Skills](./capabilities/skills.md)
- **Skills API** — The /v1/skills REST endpoints (create/upload, list, retrieve, versions create/list/delete, delete) used to manage custom Skills for the Claude API; requires the skills-2025-10-02 beta header and uploads under 30 MB with a root-level SKILL.md. _([Agent Skills](./capabilities/skills.md))_
- **Slash command** — An in-session instruction prefixed with / and typed at the start of a message in Claude Code; text after the name is passed as arguments. Includes built-in commands, bundled skills/workflows, and custom skills. _([Claude Code — Slash Commands](./claude-code/slash-commands.md))_
- **speed** — Top-level Messages API parameter; speed:"fast" (with beta fast-mode-2026-02-01 on the beta endpoint) selects Fast mode. response.usage.speed reports which speed served the request. _([Model Capabilities & Modes](./models/capabilities-and-modes.md))_
- **statusLine** — Settings object ({type:command, command, padding, refreshInterval, hideVimModeIndicator}) running a script that receives session JSON on stdin and prints the bottom status bar; subagentStatusLine renders custom subagent rows. _([Claude Code — Settings](./claude-code/settings.md))_
- **stdio transport** — MCP transport where the host launches the server as a subprocess and exchanges newline-delimited JSON-RPC over stdin/stdout; stderr is for logging only and must not be treated as an error signal. Used for local tools with no network overhead. _([Model Context Protocol (MCP)](./capabilities/mcp.md))_
- **Streamable HTTP transport** — The recommended remote MCP transport (introduced spec 2025-03-26): a single HTTP endpoint supporting POST and GET with optional Server-Sent Events; supports bearer tokens, API keys, custom headers, and OAuth 2.0. Servers must validate the Origin header against DNS-rebinding and may carry an MCP-Session-Id. _([Model Context Protocol (MCP)](./capabilities/mcp.md))_
- **strict mode** — A marketplace plugin-entry field, default true. true: plugin.json is authoritative and the marketplace entry supplements it (merge). false: the marketplace entry is the entire definition, the plugin needs no plugin.json, and conflicting component declarations fail to load. _([Claude Code Plugins](./capabilities/plugins.md))_
- **strictKnownMarketplaces** — A managed-settings allowlist restricting which marketplaces users may add: undefined = no restriction, [] = full lockdown, or a list of sources matched exactly (github repo/ref/path, full url) or by hostPattern/pathPattern regex. Checked before any network/filesystem op; cannot be overridden by user/project settings. _([Claude Code Plugins](./capabilities/plugins.md))_
- **Structured outputs** — Constraining responses to a JSON schema via output_config.format (JSON mode) and/or strict:true on a tool. Supported on Fable 5/Opus 4.8/Sonnet 4.6/Haiku 4.5 (legacy Opus 4.5/4.1). Incompatible with citations and prefilling; numeric/length constraints and recursive schemas unsupported; additionalProperties:false required. _([Model Capabilities & Modes](./models/capabilities-and-modes.md))_
- **Styles** — Presets/custom profiles that shape Claude's writing (Normal, Concise, Explanatory, Formal, Learning, plus user styles). Per official docs the Styles menu is being removed entirely: custom styles auto-convert to Skills, Concise/Explanatory/Formal are retired, and Learning is preserved as a Skill. _([Claude.ai & the Claude Apps](./platform/claude-ai.md))_
- **Subagent** — A specialized AI assistant spawned by the Claude Code main thread that runs in its own fresh, isolated context window with a custom system prompt, restricted tool set, model, and permissions, returning only its final message to the parent. _([Claude Code — Subagents](./claude-code/subagents.md))_
- **SubagentStart / SubagentStop hooks** — settings.json hook events firing in the main session when a subagent begins or completes; both support a matcher on the agent-type name. Frontmatter Stop hooks convert to SubagentStop at runtime. _([Claude Code — Subagents](./claude-code/subagents.md))_

## T

Minimum 20,000; Fable 5/Opus 4.8/4.7. _([Model Capabilities & Modes](./models/capabilities-and-modes.md))_

- **Tasks mode** — The Cowork tab in the desktop app's mode selector (alongside Chat, and Code where Claude Code desktop is available); clicking the Cowork tab switches Claude into agentic 'Tasks' execution rather than conversational chat. _([Claude Cowork](./platform/cowork.md))_
- **Teleport** — Pulling a web or iOS Claude Code session into the local terminal with `claude --teleport`; requires a claude.ai subscription. - **terminalSequence** — A universal output field emitting allowlisted terminal escape sequences (OSC 0/1/2 titles, OSC 9 incl 9;4 progress, OSC 99, OSC 777, bare BEL) for notifications; CSI, OSC 8/52/1337 are rejected. _([Claude Code — Hooks](./claude-code/hooks.md))_

- **Tool Search** — Claude Code mechanism (default on, controlled by ENABLE_TOOL_SEARCH=unset/true/auto/auto:N/false) that defers MCP tool definitions via a ToolSearch tool until needed; needs tool_reference-capable models (Haiku unsupported; Vertex AI needs Sonnet 4.5+/Opus 4.5+). - **Tools (MCP primitive)** — Server-exposed executable functions the model can invoke, discovered via tools/list and run via tools/call; surfaced in Claude Code as mcp__<server>__<tool> (or mcp__plugin_<plugin>_<server>__<tool> for plugin-bundled servers). _([Model Context Protocol (MCP)](./capabilities/mcp.md))_
- **Trusted Devices** — An org-wide Team/Enterprise beta setting (Require trusted devices) that gates viewing or steering Remote Control sessions on an enrolled device plus a sign-in no older than 18 hours, refreshed via Face ID/Touch ID/Windows Hello/passkey; Anthropic stores only the device public key and metadata, never biometrics. _([Claude Code — Dispatch, Remote Control & Routines](./claude-code/dispatch-remote-routines.md))_
