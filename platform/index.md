# Platform — the Claude surfaces

The **surfaces** are the places you actually meet Claude: chat-first apps, an autonomous desktop coworker, a visual design canvas, and a terminal-native coding agent. Each one is a distinct product with its own UI, settings, and plan gating — but they share models, [Skills](../capabilities/skills.md), [Connectors](../capabilities/connectors.md), and [Memory](./claude-ai.md#memory).

| Page | One-liner |
|---|---|
| [Claude.ai & the Claude Apps](./claude-ai.md) | The chat product family — `claude.ai` web, macOS/Windows desktop, iOS/Android, and Claude in Chrome. Composer, sidebar, modes & toggles, Memory, settings, plans, shortcuts. |
| [Claude Cowork](./cowork.md) | The agentic *Tasks* mode in Claude Desktop that works on your **real local files**, runs multi-step jobs end-to-end, schedules recurring work, and ships with enterprise governance. |
| [Claude Design](./claude-design.md) | Anthropic Labs' **prompt-to-prototype** visual workspace; talk to a live canvas to build prototypes/slides, then hand off to [Claude Code](./claude-code.md). |
| [Claude Code — Overview](./claude-code.md) | The terminal-native agentic coding tool. This page is the map; the deep reference lives in [claude-code/](../claude-code/index.md). |

## How the surfaces relate
- **Chat → autonomy:** [Claude.ai](./claude-ai.md) is conversational; [Cowork](./cowork.md) is the same desktop app turned loose on your files; [Claude Code](./claude-code.md) is the same agentic loop for codebases.
- **Design → code:** [Claude Design](./claude-design.md) produces interfaces and hands a codebase-aware bundle to [Claude Code](./claude-code.md).
- **Everywhere:** all surfaces draw on the [models](../models/index.md), and most can use [Skills](../capabilities/skills.md), [Connectors](../capabilities/connectors.md), and [Artifacts](../capabilities/artifacts.md).
